# H.264学习实践指南

本指南提供循序渐进的学习路径，帮助你通过FFmpeg源码深入理解H.264编码原理。

## 一、准备工作

### 1.1 环境配置
- ✅ 已有Xcode项目配置
- ✅ FFmpeg 6.0源码
- 📝 建议安装：
  - `ffmpeg` 命令行工具（用于测试）
  - `ffplay` 播放器（用于查看结果）
  - 十六进制编辑器（如HexFiend）

### 1.2 推荐学习顺序
```
1. NAL单元结构 → 2. 参数集(SPS/PPS) → 3. Slice结构 
   ↓
4. 宏块类型 → 5. 帧内预测 → 6. 帧间预测
   ↓
7. 变换量化 → 8. 熵编码 → 9. 去块滤波
```

**目标**: 理解NAL单元的组织方式

## 三、进阶实验

### 实验1: 实现简单的帧内预测

**任务**: 手动实现4x4 DC预测

```c
void my_pred4x4_dc(uint8_t *src, ptrdiff_t stride)
{
    int dc = 0;
    
    // 计算上方和左侧像素的平均值
    for (int i = 0; i < 4; i++) {
        dc += src[-stride + i];  // 上方
        dc += src[i*stride - 1];  // 左侧
    }
    dc = (dc + 4) >> 3;  // 除以8并四舍五入
    
    // 填充4x4块
    for (int y = 0; y < 4; y++) {
        for (int x = 0; x < 4; x++) {
            src[y*stride + x] = dc;
        }
    }
}
```

**验证**: 与FFmpeg的实现对比结果

### 实验2: 分析码率控制

**任务**: 观察不同码率控制模式的行为

1. **CBR模式**:
```bash
ffmpeg -i input.mp4 -c:v libx264 -b:v 1M -maxrate 1M -bufsize 2M cbr.h264
```

2. **VBR模式（CRF）**:
```bash
ffmpeg -i input.mp4 -c:v libx264 -crf 23 vbr.h264
```

3. **分析每帧大小**:
```bash

    grep pkt_size | head -50
```

**观察**: CBR模式下帧大小更均匀
