## 🔧 QP参数速查

| QP范围 | 质量 | 压缩率 | 适用场景 |
|--------|------|--------|----------|
| 0-17 | 极高 | 极低 | 无损/近无损 |
| 18-22 | 很高 | 低 | 高质量存档 |
| 23-28 | 高 | 中 | 一般存储（推荐） |
| 29-35 | 中 | 高 | 流媒体 |
| 36-51 | 低 | 极高 | 低码率场景 |

**QP与量化步长关系**:
- QP每增加6，量化步长翻倍
- QP每增加1，码率约变化12%

## ⚙️ FFmpeg常用命令

### 基本编码
```bash
# CRF模式（推荐）
ffmpeg -i input.mp4 -c:v libx264 -crf 23 output.mp4

# 指定码率
ffmpeg -i input.mp4 -c:v libx264 -b:v 2M output.mp4

# 指定QP
ffmpeg -i input.mp4 -c:v libx264 -qp 23 output.mp4
```

### Preset设置
```bash
# 速度优先
ffmpeg -i input.mp4 -c:v libx264 -preset ultrafast output.mp4

# 平衡（默认）
ffmpeg -i input.mp4 -c:v libx264 -preset medium output.mp4

# 质量优先
ffmpeg -i input.mp4 -c:v libx264 -preset veryslow output.mp4
```

**Preset列表**（从快到慢）:
`ultrafast` > `superfast` > `veryfast` > `faster` > `fast` > `medium` > `slow` > `slower` > `veryslow`

### Tune设置
```bash
# 电影
ffmpeg -i input.mp4 -c:v libx264 -tune film output.mp4

# 动画
ffmpeg -i input.mp4 -c:v libx264 -tune animation output.mp4

# 低延迟
ffmpeg -i input.mp4 -c:v libx264 -tune zerolatency output.mp4
```

**Tune选项**:
- `film`: 电影内容
- `animation`: 动画
- `grain`: 保留颗粒
- `stillimage`: 静态图像
- `fastdecode`: 快速解码
- `zerolatency`: 零延迟（直播）

### Profile和Level
```bash
# 设置Profile
ffmpeg -i input.mp4 -c:v libx264 -profile:v baseline output.mp4
ffmpeg -i input.mp4 -c:v libx264 -profile:v main output.mp4
ffmpeg -i input.mp4 -c:v libx264 -profile:v high output.mp4

# 设置Level
ffmpeg -i input.mp4 -c:v libx264 -level 4.0 output.mp4

# 组合使用
ffmpeg -i input.mp4 -c:v libx264 -profile:v high -level 4.1 output.mp4
```

### GOP设置
```bash
# 设置GOP大小（关键帧间隔）
ffmpeg -i input.mp4 -c:v libx264 -g 250 output.mp4

# 设置B帧数量
ffmpeg -i input.mp4 -c:v libx264 -bf 3 output.mp4

# 禁用B帧
ffmpeg -i input.mp4 -c:v libx264 -bf 0 output.mp4
```

### 两遍编码
```bash
# 第一遍
ffmpeg -i input.mp4 -c:v libx264 -b:v 2M -pass 1 -f null /dev/null

# 第二遍
ffmpeg -i input.mp4 -c:v libx264 -b:v 2M -pass 2 output.mp4
```

### 硬件加速
```bash
# NVIDIA NVENC
ffmpeg -i input.mp4 -c:v h264_nvenc -preset fast output.mp4

# Intel QSV
ffmpeg -i input.mp4 -c:v h264_qsv -preset fast output.mp4

# AMD AMF
ffmpeg -i input.mp4 -c:v h264_amf -quality speed output.mp4

# Apple VideoToolbox (macOS)
ffmpeg -i input.mp4 -c:v h264_videotoolbox -b:v 2M output.mp4
```

## 🔍 分析命令

### 查看视频信息
```bash
# 基本信息
ffprobe -v error -show_format -show_streams input.mp4

# 只看视频流
ffprobe -v error -select_streams v:0 -show_entries stream input.mp4

# 查看编码参数
ffprobe -v error -select_streams v:0 \
  -show_entries stream=codec_name,profile,level,width,height,bit_rate \
  input.mp4
```

### 帧信息分析
```bash
# 查看所有帧
ffprobe -show_frames input.mp4

# 只看关键帧
ffprobe -show_frames -select_streams v \
  -show_entries frame=pict_type,pkt_pts_time \
  input.mp4 | grep "pict_type=I"

# 统计帧类型
ffprobe -show_frames -select_streams v \
  -show_entries frame=pict_type -of csv=p=0 \
  input.mp4 | sort | uniq -c
```

### 质量分析
```bash
# PSNR
ffmpeg -i original.mp4 -i encoded.mp4 \
  -lavfi psnr -f null -

# SSIM
ffmpeg -i original.mp4 -i encoded.mp4 \
  -lavfi ssim -f null -

# VMAF（需要安装libvmaf）
ffmpeg -i encoded.mp4 -i original.mp4 \
  -lavfi libvmaf -f null -
```

## 📐 宏块和预测模式

### 宏块大小
- 基本单位: **16x16像素**
- 亮度: 16x16
- 色度(4:2:0): 8x8

### 帧内预测模式数量
- 4x4亮度: **9种**
- 8x8亮度: **9种**
- 16x16亮度: **4种**
- 8x8色度: **4种**

### 帧间块划分
- 16x16
- 16x8, 8x16
- 8x8 (可进一步划分为 8x4, 4x8, 4x4)

## 🎨 色度采样格式

| 格式 | 说明 | 亮度:色度比例 | 带宽 |
|------|------|--------------|------|
| 4:4:4 | 全采样 | 1:1:1 | 100% |
| 4:2:2 | 水平2:1子采样 | 4:2:2 | 67% |
| 4:2:0 | 水平垂直2:1子采样 | 4:2:0 | 50% |

**最常用**: 4:2:0（节省带宽，视觉影响小）

## 💡 优化建议

### 质量优先
```bash
ffmpeg -i input.mp4 -c:v libx264 \
  -preset slower \
  -crf 18 \
  -tune film \
  output.mp4
```

### 速度优先
```bash
ffmpeg -i input.mp4 -c:v libx264 \
  -preset veryfast \
  -crf 23 \
  output.mp4
```

### 文件大小优先
```bash
ffmpeg -i input.mp4 -c:v libx264 \
  -preset veryslow \
  -crf 28 \
  -b:v 1M -maxrate 1M -bufsize 2M \
  output.mp4
```

### 兼容性优先
```bash
ffmpeg -i input.mp4 -c:v libx264 \
  -profile:v baseline \
  -level 3.0 \
  -pix_fmt yuv420p \
  output.mp4
```

### 直播/低延迟
```bash
ffmpeg -i input.mp4 -c:v libx264 \
  -preset veryfast \
  -tune zerolatency \
  -bf 0 \
  -g 60 \
  output.mp4
```

## 🐛 常见问题速查

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 块效应明显 | QP过高 | 降低CRF或提高码率 |
| 文件过大 | 码率过高 | 提高CRF或降低码率 |
| 编码太慢 | preset太慢 | 使用faster/fast |
| 兼容性差 | Profile太高 | 使用baseline |
| 运动模糊 | B帧过多 | 减少-bf参数 |
| 延迟高 | GOP太大 | 减小-g参数 |
