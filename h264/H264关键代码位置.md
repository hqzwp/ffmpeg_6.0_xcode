# H.264关键代码位置导航

本文档帮助你快速定位FFmpeg中H.264编解码的关键代码位置，方便在Xcode中调试学习。

## 一、编码器相关

### 1.1 libx264编码器封装
**文件**: `ffmpeg-6.0/libavcodec/libx264.c`

| 函数名 | 行号 | 功能说明 |
|--------|------|----------|
| `X264_init()` | ~900 | 初始化x264编码器，设置参数 |
| `X264_frame()` | 561 | 编码一帧，核心编码入口 |
| `X264_close()` | ~1100 | 关闭编码器，释放资源 |
| `setup_frame()` | ~400 | 准备输入帧数据 |

**关键数据结构**:
```c
typedef struct X264Context {
    x264_param_t    params;      // 编码参数
    x264_t         *enc;         // 编码器实例
    char *preset;                // 预设
    char *tune;                  // 调优
    float crf;                   // 质量因子
    int cqp;                     // 量化参数
} X264Context;
```

**调试建议**:
- 在 `X264_frame()` 第577行设置断点，观察编码流程
- 在 `X264_init()` 查看参数设置过程

|--------|------|----------|

**调试建议**:

- 观察 `decode_nal_units()` 如何解析NAL

### 2.2 Slice处理
**文件**: `ffmpeg-6.0/libavcodec/h264_slice.c`

| 函数名 | 行号 | 功能说明 |
|--------|------|----------|
| `ff_h264_queue_decode_slice()` | 2019 | 提交slice进行解码 |
| `h264_slice_header_parse()` | 1664 | 解析slice头部 |
| `decode_slice()` | 2514 | 解码slice数据 |
| `h264_slice_header_init()` | 934 | 初始化slice头部 |

**关键流程**:
```
h264_decode_frame()
  └─> decode_nal_units()
      └─> ff_h264_queue_decode_slice()
          └─> h264_slice_header_parse()
          └─> decode_slice()
              └─> ff_h264_decode_mb_cabac/cavlc()
                  └─> ff_h264_hl_decode_mb()
```

## 八、调试技巧

### 8.1 推荐断点位置

#### 编码流程
1. `libx264.c:X264_frame()` - 编码入口
2. `libx264.c:setup_frame()` - 帧准备

#### 解码流程
1. `h264dec.c:h264_decode_frame()` - 解码入口
2. `h264_slice.c:decode_slice()` - Slice解码
3. `h264_cabac.c:ff_h264_decode_mb_cabac()` - 宏块解码
4. `h264_mb.c:ff_h264_hl_decode_mb()` - 宏块重建

### 8.2 关键变量观察

```c
// 在调试时观察这些变量
h->mb_type[mb_xy]        // 宏块类型
sl->qscale               // 量化参数
sl->mv_cache             // 运动矢量缓存
h->cur_pic_ptr           // 当前图像指针
sl->slice_type           // Slice类型
```

### 8.3 日志输出

在代码中添加调试输出：
```c
av_log(h->avctx, AV_LOG_DEBUG, "MB %d: type=%d qp=%d\n", 
       mb_xy, mb_type, sl->qscale);
```

运行时启用调试日志：
```bash
export AV_LOG_FORCE_COLOR=1
./ffmpeg -loglevel debug -i input.mp4 ...
```
